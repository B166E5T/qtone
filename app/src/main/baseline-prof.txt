# Baseline Profile for Qtone IPTV
#
# This file tells Android's ART runtime which classes and methods to
# pre-compile into native machine code at install time (AOT compilation).
# Without this, the JIT compiler has to discover and optimize these code
# paths at runtime, causing jank during the first few minutes of use —
# especially noticeable on lower-powered hardware like Fire TV Stick.
#
# The profileinstaller library (already in build.gradle.kts) reads this
# file from the APK and applies it during the first launch after install.
# Subsequent launches benefit from the pre-compiled code immediately.
#
# Format: HSPMethodSignature or HSPClassDescriptor
#   H = Hot (frequently called)
#   S = Startup (called during app startup)
#   P = Post-startup (called shortly after startup)
#
# Rules use wildcards:
#   ** = any class/package
#   * = any method name
#   (**) = any parameter list
